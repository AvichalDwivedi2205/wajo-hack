FO REACH · OFFLINE HELPER

Your credentials stay with you.

Download this file and open the downloaded copy in your browser. It makes no network requests and does not configure a server. Nothing is generated until you choose the button below.

Each credential contains 32 cryptographically random bytes, encoded as 43 unpadded base64url characters. Save both credentials in your own password vault before closing this page. Their digests cannot recover them.

1. Generate only when you are ready

This creates two independent credentials for one deployment. It does not create an account or grant device access.

Select and copy each value into separate entries in your own vault. Never send the owner credential or an authenticated owner session to Fo. Do not paste either credential into chat, screenshots, logs or configuration files.

No credentials have been generated.

2. Save your credentials, then export digests

The export contains only SHA-256 digests of the exact credential strings (UTF-8, no newline). It contains no plaintext credential, origin or access deadline.

3. Approve the exact configuration separately

Give the operator only the digest export. Review the approved HTTPS origin, owner/MCP roles, these digests, backend and exact UTC deadline before authorizing installation and a service restart. The deadline must be within the next 24 hours; there is no automatic renewal.

Enter your owner credential only into the approved Fo Reach HTTPS sign-in form. Enter your MCP credential only into Fo’s secure post-registration credential form. This page sends neither value anywhere.

Closing or clearing this page removes the displayed values. Your browser extensions, clipboard history and password vault remain under your control. This helper stores nothing for a later visit.
