# Fo Reach demo plan: catch the number before the client does

The relatable problem: someone is about to recommend a rollout using an outdated conversion figure. Fo Reach checks the approved evidence, catches the discrepancy, prepares a useful client review, and makes the output reversible. The deck is the result of the work; the decision is the story.

Opening disclosure: **“Synthetic client files. Real software running on this Mac.”** The implementation supports this explicit Alder fixture/cohort and fixed template. Do not imply arbitrary file ingestion or an unconstrained analyst agent.

## Suggested continuous sequence — approximately two minutes

| Time | Visible action | What it proves |
| --- | --- | --- |
| 0–12s | Show the prior handout's 5.5% claim and ask Fo to prepare the client review from the scoped folders | Familiar problem with a concrete consequence; no manufactured countdown |
| 12–25s | Allow the three folders locally; explain “these ten files, nothing else” and expiry | Deliberate, bounded local access |
| 25–55s | Show current vs superseded sources and actual evidence trace: 660 paid − 120 full refunds = 540; 540 / 12,000 = 4.5%; existing gate 5%; hold | Evidence changes the recommendation; the rule was not invented after seeing the result |
| 55–75s | Review three exact slide previews, both comparison images, owner/readout and destination; approve locally | Useful proposed work and a specific human control point |
| 75–98s | Fo commits the approved plan; open the actual generated deck/PDF and inspect the three PDF renders | Real editable PowerPoint file and PDF created on this Mac, with independent checks |
| 98–108s | Show originals unchanged and verified job metadata briefly | Preserved source evidence; no long terminal hash dump |
| 108–125s | Prepare undo, approve removal separately, let Fo commit, and show generated outputs removed while originals remain | Controlled reversibility |

Narration at output: **“An editable PowerPoint deck and PDF, created here on this Mac.”** One-line approval explanation: **“This approval covers these sources, these slides and this destination.”** The proposed checkout remains a hypothesis; no measured uplift is claimed.
